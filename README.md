# Student-Performance-Analysis
## Project overview
This project analyzes student performance data to identify factors with academic performance and identify students who may be at risk of failing.
##  Objectives 
- Clean and prepare the student performance dataset.
- Explore factors associated with student performance.
- Analyze relationship between different variables.
- identify patterns in student performance.
- Build a classification model to predict whether a student is likely to pass or fail.
- Evaluate the performance of the machine learning model.
  ## Tools Used
  - Python
  - pandas
  - Numpy
  - Matplotlib
  - Seaborn
  - power bi
  - SciKit-learn
    ## project workflow
    1. Data cleaning
    2. Exploratory data analysis
    3. Data visualization
    4. Features preparation
    5. Machine learning
    6. Model evaluation
    7. further analysis with power bi
